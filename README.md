# jc-football · 竞彩足球数据与结构测算工具包

一个**自包含、可移植**的竞彩足球工作包：把「取数 → 去水 → 建腿池 → 组合测算 →
出票 → 报告 → 复盘 → 账本」收成一条命令行链，并把七天实战沉淀的**规则**（30 条铁律 +
37 条经验 + 17 步自检清单）一起带走。

> ⚠️ 本项目只做**体育赛事数据分析与结构测算**，**不构成投注建议**，不承诺任何收益。
> 未满 18 周岁禁止购买彩票，请理性购彩。

## 为什么值得带走

竞彩的真实难点不是"猜谁赢"，而是三件事：

1. **口径**：官方赔率含水位，必须**去水**才是可比的市场隐含概率。
2. **结构**：同样三个判断，`3串1` 与 `3串3`、`2串1` 的盈亏分布完全不同。
3. **反直觉的数学**：「错 1 腿回本」与「大概率赚钱」**互斥** —— 盈利概率上界由腿数唯一决定
   （N=3 → 49.5%／N=4 → 48.5%／N=5 → 44.6%），多买票只会**稀释**盈利概率（48.5% → 29.7%）。

本包把这三件事都变成了可执行的代码与可复核的数字。

## 30 秒上手

```bash
cd jc-football

# 1) 抓取赔率并落盘快照（必须带 UA + Referer，否则被 WAF 拦）
python -m jc fetch

# 2) 建腿池，看候选腿
python -m jc legs --date 2026-10-16 --league 英超,西甲,德甲,意甲,法甲

# 3) 搜索"错 1 腿回本 + 最优盈利概率"的方案
python -m jc scheme --date 2026-10-16 --rank prof --legs 4

# 4) 测算一个具体组合（支持复式，多档用 +）
python -m jc payout --date 2026-10-16 --legs "周六019:ttg:3+4+5+6,周六026:hhad:a,周六029:hhad:h"

# 5) 生成出票单 / 分析报告 / 复盘
python -m jc ticket --date 2026-10-16 --assign "票①=周六017:had:a,周六020:had:h"
python -m jc report --date 2026-10-16
python -m jc review
```

## 两个必须避开的取数陷阱

1. **禁止 `dict.update()` 跨池合并同一场次**。接口里非本池的玩法字段为空，
   `update()` 会把已取到的赔率整块覆盖成 `None`（症状：只有第一场有数据）。
   → 本包 `odds.merge_match()` **逐字段取非空值**。
2. **`had` 池会缺场次**。实测 2026-10-16：`周六025 拜仁 vs 莱红牛` 在 `ttg`/`hhad` 有、`had` 无。
   → 基准索引取**覆盖最全的池**（`ttg`），绝不以 `had` 为准。

## 环境

- Python ≥ 3.10，**零第三方依赖**（仅标准库）。
- 网络需能访问 `webapi.sporttery.cn`。

## 合规

- 数据来源：中国体育彩票竞彩官方接口，仅作个人复盘与结构测算。
- 不做代购、不做资金归集、不做"包中/稳赚"宣传、不传播他人票面。
- 所有输出均含风险披露与"理性购彩"提示。
