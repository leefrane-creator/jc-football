# 竞彩足球分析师（jc-football-analyst）

覆盖中国体育彩票竞彩足球全部玩法的比赛分析专家，融合基本面与赔率盘口双轨验证，输出结构化推荐、置信度与风险提示。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **全玩法覆盖**：胜平负、让球胜平负、比分、总进球数、半全场胜平负、上下盘（亚盘让球方向 / 大小球）六种玩法，每种独立给出判断逻辑与输出结构。
- **官方数据接口**：内置竞彩官方 JSON 接口取数手册（`getMatchCalculatorV1.qry`，`poolCode=had/hhad/ttg/hafu/crs`），含请求头、字段映射、单关/过关状态（`bettingSingle`）与"过期场次不留赔率、须赛前留快照"的时效铁律。
- **输入数据需求明确**：对阵双方、赛事、开赛时间、赔率为基础必填项；近期战绩、主客场、伤停、赛程密度、战意为增强项；可联网时实时抓取中国体育彩票官方、懂球帝等公开信息，并交叉校验、标注时间戳。
- **缺数据降级方案**：无法获取实时数据时严禁编造，明确标注「未获取」，并按缺赔率 / 缺阵容 / 缺近况三类情形降级给出条件式结论。
- **赔率解读**：初盘与即时盘变化的读法、欧赔与亚盘的差异及市场倾向判断、常见盘口信号速查表。
- **置信度量化**：5 维度 × 0–2 分 = 10 分制透明公式，换算高 / 中 / 低置信星级，杜绝拍脑袋。
- **统一输出格式**：赛事概览 → 分玩法分析（推荐 / 置信度 / 关键依据 / 风险提示）→ 综合结论与风险提示。
- **实战经验库（持续学习）**：以真实复盘沉淀硬铁律（总进球档位"多留一档"、≥3 腿必用容错过关、"双选"不隔离风险等），并按案例滚动更新、定期回顾校准。

## 使用示例

- 分析今晚【主队 vs 客队】这场竞彩比赛，请覆盖胜平负、让球胜平负、比分、总进球、半全场胜平负和上下盘全部玩法。
- 解读这场比赛的初盘与即时赔率变化，分析欧赔与亚盘的差异及其反映的市场倾向。
- 结合近期战绩、主客场、伤停与赛程密度，帮我评估这期竞彩串关组合的合理性与风险。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\lee\.workbuddy\plugins\marketplaces\my-experts\plugins\jc-football-analyst\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r jc-football-analyst.zip jc-football-analyst/
```
